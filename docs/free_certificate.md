# Free-Certificate Theorem — parts (a), (b) PROVEN; (c) CONJECTURE

**Status:** (a), (b) proven 2026-09-14 (numerically certified at n=6, machine precision).
(c) is a conjecture and is NOT to be cited as a result. Builds on
`goldilocks/docs/R1_symmetry.md` (R1 = the sector-trivial special case Q ∝ I, and the
source of the symmetry machinery reused verbatim in (b)).

## Setup

Hilbert space ℂ^(2^n), computational basis {|x⟩ : x ∈ {0,1}^n}. A classical constraint
function q : {0,1}^n → ℝ defines the **diagonal charge** Q = Σ_x q(x)|x⟩⟨x| and the
**sectors** S_c = {x : q(x) = c}; because Q is diagonal, each Q-eigenspace
H_c = span{|x⟩ : x ∈ S_c} is spanned by computational-basis states.

**Proposal channel** E: prepare |x⟩, apply any finite composition of (i) unitaries U with
[U, Q] = 0 (equivalently, generated by Hamiltonians H(t) with [H(t), Q] = 0 for all t)
and (ii) CPTP noise maps N(ρ) = Σ_a K_a ρ K_a† whose every Kraus operator satisfies
[K_a, Q] = 0; then measure in the computational basis. Write
q_E(y|x) = ⟨y| E(|x⟩⟨x|) |y⟩.

## Theorem (a) — sector support (free feasibility certificate)

*For every x and every outcome y with q(y) ≠ q(x): q_E(y|x) = 0. Outcomes stay in the
start sector with probability 1, for any circuit depth, any evolution time, any number of
noise rounds, and any n.*

**Proof.** An operator A with [A, Q] = 0 is block-diagonal across distinct Q-eigenvalues:
for eigenprojectors P_c of Q, A = Σ_c P_c A P_c (standard commutant fact: P_c is a
polynomial in Q, so [A, P_c] = 0, hence P_c A P_d = A P_c P_d = 0 for c ≠ d). Each U and
each K_a therefore maps H_c into H_c. Let ρ_0 = |x⟩⟨x| with x ∈ S_c, so
P_c ρ_0 P_c = ρ_0. For a unitary step, P_c (UρU†) P_c = U(P_c ρ P_c)U† preserves the
property "ρ = P_c ρ P_c". For a noise step, N(ρ) = Σ_a K_a ρ K_a† with
K_a = Σ_d P_d K_a P_d likewise preserves it (cross terms vanish). By induction,
E(ρ_0) = P_c E(ρ_0) P_c. Since |y⟩ ∈ H_d with d = q(y) ≠ c, ⟨y|E(ρ_0)|y⟩ =
⟨y|P_c E(ρ_0) P_c|y⟩ = 0 because P_c|y⟩ = 0. ∎

**Remark (dephasing is doubly free).** Any diagonal jump operator — in particular every
Z_i of the dominant dephasing channel — commutes with EVERY diagonal Q automatically. So
for diagonal charges the R1 noise model is sector-preserving with no extra assumption:
dephasing costs neither exactness (R1) nor feasibility (a).

**Remark (contrast with the classical side).** The classical analogue of "outcome in
S_c" for exact proposals is the M06-measured completeness certificate (censored ≥300 s at
n ≥ 24). Theorem (a) prices the same guarantee at zero: the dynamics cannot leave the
sector, so no proof is ever produced or needed.

## Theorem (b) — per-sector proposal symmetry (R1, sector-restricted)

*Assume additionally the R1 hypotheses: H real symmetric, noise unravelled by real
diagonal jump operators of uniform rate (pure dephasing √γ Z_i), and [H, Q] = 0. Then
q_E(y|x) = q_E(x|y) for ALL pairs (x, y) — within every sector simultaneously — and the
channel is a valid Metropolis–Hastings proposal with log q ≡ 0 for any target
distribution π restricted to the start sector.*

**Proof.** Symmetry: the R1 jump-unravelling argument applies verbatim — condition on a
jump realization ω; the conditional propagator W(ω) = U(t−t_m) Z_{i_m} ⋯ Z_{i_1} U(t_1)
is a product of real symmetric factors (U(s)ᵀ = U(s) for H real symmetric; Z_iᵀ = Z_i),
so W(ω)ᵀ = W(ω̃) with ω̃ the time-reversed realization, and the realization law is
reversal-invariant (Poisson times = order statistics of iid uniforms; iid site labels).
Averaging gives q_E(y|x) = q_E(x|y). Nothing in that argument is affected by adding
[H, Q] = 0. Sector restriction: by (a), q_E(y|x) = 0 = q_E(x|y) whenever q(x) ≠ q(y),
so the symmetric kernel decomposes as a direct sum of symmetric kernels, one per sector.
MH validity on a sector: for π_c ∝ π·1_{S_c}, the acceptance min{1, π_c(y)/π_c(x)} with
a symmetric in-sector proposal satisfies detailed balance on S_c; the chain started in
S_c never proposes outside it (probability-0 proposals are never realized). Mixtures over
t, γ, or circuit draws preserve both properties (mixtures of symmetric sector-preserving
kernels are symmetric and sector-preserving). ∎

**Numerical certification (2026-09-14, `docs/free_certificate_cert.py`):** n = 6,
Q = Hamming weight, H = random-coupling XY hopping + diagonal disorder (real symmetric,
[H, Q] = 0), full Lindblad e^{tL} with γ = 0.7, t = 3.0, all 64×64 transition entries:
max cross-sector leakage = 0.0 (exactly); max symmetry defect = 1.9e-16 (machine
precision). Both parts certified.

**Hardware instantiations of the hypotheses.** Q = Hamming weight (particle number):
XY/iSWAP gate sets conserve it exactly and natively; H_XY + diagonal phase disorder is
real symmetric. Q = energy is the quench's approximate charge (D01 shell mechanism —
conservation only approximate, so (a) holds only approximately there; the exact-charge
case is the upgrade). Parity/stabilizer charges satisfy the algebra but their sectors are
classically easy (Gauss) — compilation demos only.

## Conjecture (c) — post-selection self-audit (NOT PROVEN)

*Claim (conjectured): under noise with an additional non-commuting component (e.g.
amplitude damping), discarding the shots whose outcome violates q(y) = q(x) — a classical
O(n²) check — restores (a) exactly and preserves (b)'s symmetry, so that noise costs
retries, never correctness.*

Why this is NOT a corollary: the discard event has state-dependent probability (the
R1 counterexample mechanism — σ⁻ jumps are state-dependent precisely because
(σ⁻)†σ⁻ ≠ I), so the KEPT sub-channel is E_keep(ρ) = P_c E(ρ) P_c with a normalization
⟨keep⟩ that in general depends on x. Symmetry of the conditioned kernel
q_E(y|x)/p_keep(x) requires either p_keep constant on the sector or a cancellation that
must be exhibited. R1's own numerics (amplitude damping κ = 0.1Δ ⇒ defect ~2e-1 in the
UNCONDITIONED kernel) show there is something real to prove. Until (c) is proven or
bounded, hardware claims must either bound the post-selected asymmetry bias or estimate
q-ratios for the non-commuting component (same G03 fork as R1).

## What this buys (scope, honestly)

(a)+(b) together: a device with a natively conserved diagonal charge is an exact,
noise-robust (dephasing-robust), log q ≡ 0 MH proposal WITHIN a sector, with feasibility
of every shot guaranteed by physics rather than by classically-scaling certificates —
the NOETHER selection rule's theorem backbone. What it does not buy: any speed claim
(that is P01's empirical question), anything about amplitude damping (see (c)), or
fair/uniform sampling within the sector (proposal symmetry ≠ uniformity; fairness at
scale is a separate measured question — annealer literature says assume nothing).
